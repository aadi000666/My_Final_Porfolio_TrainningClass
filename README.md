# Aditya Maurya Portfolio

This project is a simple personal portfolio website built with HTML and CSS.

## About
It showcases information about Aditya Maurya, including:
- personal details
- education background
- hobbies and interests
- academic marksheets

## Files
- `index.html` – main page content
- `portfolio.css` – styling for the portfolio
- `my_photo.jpg` – profile image
- `diploma_marksheet.jpg` – diploma marksheet
- `marksheet.jpg` – high school marksheet

## How to run
1. Open the project folder in a browser.
2. Double-click `index.html` or serve the folder using a local web server.
3. The website will load in the browser.
